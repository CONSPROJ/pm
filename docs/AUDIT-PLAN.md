# برنامهٔ بازبینی حرفه‌ای سایت (پیش از انتقال)

این فهرست ترتیب کار است. هر بند فقط یک بار انجام می‌شود و شمارهٔ بند HANDOFF کنارش می‌آید. اگر کار نیمه ماند، از اولین بند تیک‌نخورده ادامه پیدا می‌کند.

معیار هر بند در `docs/FEATURE-RULES.md` است:
- بی‌تکرار؛ بدون شرط ثابت
- الگوی یکسان رابط
- آزمون روی گوشی و دسکتاپ با ثبت واقعی
- بی‌جعل هویت
